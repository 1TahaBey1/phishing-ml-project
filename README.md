Dataset of the project is available at -->  https://www.kaggle.com/datasets/akashkr/phishing-website-dataset 

This project aims to detect phishing websites using different machine learning algorithms.
Algorithms Used: Decision Tree, Naive Bayes, k-Nearest Neighbors (k-NN)

Evaluation Metrics: Accuracy, Precision, Recall, F1-score, Confusion Matrix
Results

Algorithm             Accuracy 
Decision Tree    -->   95.75% 
k-NN             -->   93.6% 
Naive Bayes      -->   58.2% 

How to Run

Install required libraries:
pandas, scikit-learn, matplotlib, seaborn

Run the code: python main.py
